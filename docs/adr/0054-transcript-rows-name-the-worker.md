# Transcript Rows Name the Worker

Status: accepted

When an agent coordinates its Hive, the transcript shows each call the way the rest of the product already speaks about Workers, rather than the way Codex or T3 Code speak about sub-agents. A row says **Worker**, never "sub-agent" or "agent": the bee analogy is intended (a Worker takes any job; the **Queen Session** originates the Hive rather than commanding it), and the Hive panel, sidebar and identity header already say Worker. A row names the Session it acts on as "verb Worker (Agent definition name) · current title", read from the same Hive query as the Hive panel so both always show the same title; a Session that is not a Worker reads "session · title": the Queen, or a Session the call launched or created, by its requested title until the Hive knows it. Any other target, including a Session outside the transcript's Hive, reads a bare "Worker", a fork of an unresolved Session reads "session", and a report reads "Reported to the Queen", "Reported to its parent" or "Reported to N Workers" when that is where it went. The row icon is the `Pickaxe` that ADR 0020 gives every Worker, not a separate robot or bot glyph, so a Worker has one glyph everywhere.

Following the **Codex parity baseline**, a `wait` call gets no row: a spawn row instead carries the Worker's live state, in the Hive panel's words, and an **Open** control. We deliberately depart from Codex and T3 Code in two places. Rows say Worker rather than agent or subagent. Consecutive spawns are not grouped under a "Created 3 agents" header, because the Hive panel is the only place Workers are listed and a grouped, expandable header would be a second Worker list.

Two rows cannot name their Worker yet: Delegation reviews (accept, verify, request revision) carry only a Delegation id, so they read "Accepted a Worker's work", and a spawn made inside a script has no recorded result, so it keeps its requested name without live state or Open.

Considered and rejected: T3 Code's full sub-agent cards (model, progress line, elapsed time), Codex's per-agent activity rows ("Euler finished") and composer strip, and keeping a robot icon beside or instead of the pickaxe. The Hive panel and the Session Hub's Hive row already carry that information.
