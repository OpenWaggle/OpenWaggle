Run independent agent Sessions as visible Hives: a Queen can spawn durable Workers in shared or
isolated workspaces, while the desktop app, CLI, MCP clients, and agents coordinate through the same
local Session Host. The release also adds durable Follow-up and Steering controls, searchable and
exportable transcripts, optional Markdown Agent definitions, restricted external-agent profiles,
and explicit one-time migration recovery.
